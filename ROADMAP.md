# Roadmap

## Phase 1 — Foundation

- Create Android multi-module project
- Configure Wear OS app module
- Configure optional phone companion module
- Add shared core module
- Add CI basics
- Add app icons and package naming

## Phase 2 — Wear OS file browser MVP

- Round-screen optimized navigation
- File/folder list UI
- Breadcrumb or compact path navigator
- Open, rename, copy, move, delete
- Favorites and recent locations
- Storage usage screen
- Permission onboarding

## Phase 3 — Media features

- Image gallery
- Audio player
- Video player / preview
- File metadata screen
- Thumbnail cache with battery limits

## Phase 4 — Remote management

- HTTP server on watch
- QR code pairing screen
- Browser upload/download UI
- PIN/session security
- Auto-stop server on low battery or timeout

## Phase 5 — Advanced user mode

- ADB guide
- Diagnostics page
- Extended storage notes
- Risk warnings
- Export logs

## Phase 6 — Phone companion

- Pairing and setup wizard
- File transfer between phone and watch
- Remote server control
- Storage and battery dashboard

## Phase 7 — Polish

- Accessibility
- Rotary input support
- Haptics
- Localization
- Battery profiling
- Play Store readiness
