# Feature Backlog

## Must have

- File browsing
- Basic file operations
- Permission onboarding
- Round watch UI
- Settings
- Battery-safe behavior

## Should have

- Media gallery
- Audio playback
- Video preview
- HTTP remote file manager
- QR pairing
- Storage usage dashboard
- Recent files
- Favorites

## Could have

- FTP server
- WebDAV server
- Phone companion
- Archive extraction/creation
- Cloud integrations
- Root/ADB helper documentation
- Plugin system

## Won't do initially

- Unsafe always-on background server
- Hidden full-storage access without user action
- Root-only behavior as a core requirement

## Permission notes

Android storage access is restricted. The app should support normal media/document permissions and explain limitations. Full memory access should be documented as an advanced ADB/developer workflow, not promised as a normal permission.
