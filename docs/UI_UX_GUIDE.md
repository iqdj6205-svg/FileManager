# Wear OS UI/UX Guide

## Design goals

- Usable on round screens
- Fast one-handed navigation
- Minimal typing
- Clear destructive-action confirmations
- Battery-friendly visuals

## Main patterns

### Home screen

Large chips:

- Files
- Media
- Remote
- Settings
- Advanced

### File list

- Directory items first
- Icons by file type
- Filename primary
- Size/date secondary only when enough space
- Long press opens action sheet

### Actions

Use compact action sheets:

- Open
- Share
- Rename
- Copy
- Move
- Delete
- Details

### Round screen rules

- Keep critical content away from screen edges
- Use vertical scrolling
- Avoid multi-column layouts on watch
- Use concise labels
- Avoid persistent dense toolbars

### Gestures

- Tap: open
- Long press: actions
- Swipe back: up/back
- Rotary: scroll
