# File Actions

## Watch action model

File operations must be optimized for a tiny screen.

Recommended UI flow:

1. Tap folder to open.
2. Tap file to preview/open.
3. Long press file/folder to open action sheet.
4. Confirm destructive operations.
5. Prefer preset names or phone companion input for rename/create folder.

## Actions

- Open
- Share
- Rename
- Copy
- Move
- Delete
- Details
- Favorite

## Safety

Delete and overwrite must always require confirmation in the app UI. Remote destructive operations require authentication and explicit enablement.
